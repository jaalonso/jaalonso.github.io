    Reto 32: Criterio del sucesor para funciones de extracción

    José A. Alonso

    23-11-2026

    También disponible en:

    English

    Una subsucesión se obtiene aplicando a la sucesión original una función de extracción; es decir, una función \(\varphi : \mathbb{N} \to \mathbb{N}\) estrictamente creciente. Por ejemplo, la subsucesión \[ u_0, u_2, u_4, u_6, \dots \] se obtiene con la función de extracción \(\varphi\) definida por \(\varphi(n) = 2n\).

    Demostrar que si \[ \forall n, \varphi(n) < \varphi (n+1), \] entonces \(\varphi\) es una función de extracción.

    Para ello, completar la siguiente teoría en Lean 4:

    import Mathlib.Basic.Real.Basic

def IsExtraction (φ : ℕ → ℕ) : Prop :=
  StrictMono φ

variable (φ : ℕ → ℕ)

example
  (hφ : ∀ n, φ n < φ (n + 1))
  : IsExtraction φ :=
by

    Soluciones propuestas

    1. Demostraciones en lenguaje natural

    Sea \(\varphi : \mathbb{N} \to \mathbb{N}\) tal que \[ \forall n \in \mathbb{N}, \varphi(n) < \varphi(n+1) \tag{1} \] Hay que demostrar que \(\varphi\) es una función de extracción: es decir, \[ \forall i j \in \mathbb{N}, i < j \to \varphi(i) < \varphi(j) \]

    1ª demostración (inducción sobre \(j\))

    Sean \(i, j \in \mathbb{N}\) con \(i < j\). Probamos por inducción sobre \(j\) que \(\varphi(i) < \varphi(j)\).

    Caso \(j = 0\). La hipótesis \(i < 0\) es imposible, ya que ningún natural es menor que \(0\). Por tanto, el resultado se cumple trivialmente.

    Paso \(j = n + 1\). Supongamos como hipótesis de inducción que, \[ i < n \to \varphi(i) < \varphi(n) \tag{ih} \] y tenemos que demostrar que \[ i < n+1 \to \varphi(i) < \varphi(n+1) \] Para ello, sea \[ i < n+1 \tag{2} \] y tenemos que demostrar que \[ \varphi(i) < \varphi(n+1) \] Lo haremos distinguiendo dos casos, ya que de (2) se sigue que \[ i < n \lor i = n \] Caso \(i < n\). Entonces, \[ \begin{array}{llll} \varphi(i) &< \varphi(n) &&\text{[por (ih), ya que \(i < n\)]} \\ &< \varphi(n+1) &&\text{[por (1)]} \end{array} \] Caso \(i = n\). Entonces, \[ \begin{array}{llll} \varphi(i) &= \varphi(n) &&\text{[porque \(i = n\)]} \\ &< \varphi(n+1) &&\text{[por (1)]} \end{array} \]

    2ª demostración (inducción sobre la desigualdad)

    Sean \(i, j \in \mathbb{N}\) con \(i < j\), o, equivalentemente, \(i + 1 \leq j\). Probamos por inducción sobre \(j\), a partir de \(j = i + 1\), que \(\varphi(i) < \varphi(j)\).

    Caso base \(j = i + 1\). Hay que probar \(\varphi(i) < \varphi(i+1)\), que es (1) para \(n = i\).

    Paso inductivo. Sea \(m \geq i + 1\) y supongamos que \[ \varphi(i) < \varphi(m) \tag{ih} \] Entonces, \[ \begin{array}{llll} \varphi(i) &< \varphi(m) &&\text{[por (ih)]} \\ &< \varphi(m+1) &&\text{[por (1)]} \end{array} \]

    3ª demostración (lema de Mathlib)

    Basta aplicar el lema strictMono_nat_of_lt_succ de Mathlib, que afirma que una función \(f : \mathbb{N} \to \alpha\), con \(\alpha\) un preorden, es estrictamente creciente si \(f(n) < f(n+1)\) para todo \(n\). Como \(\varphi\) cumple (1), es estrictamente creciente, y por definición, una función de extracción.

    2. Demostraciones en Lean 4

    import Mathlib.Basic.Real.Basic

def IsExtraction (φ : ℕ → ℕ) : Prop :=
  StrictMono φ

variable (φ : ℕ → ℕ)

-- 1ª demostración
-- ===============

example
  (hφ : ∀ n, φ n < φ (n + 1))
  : IsExtraction φ :=
by
  intro i j hij
  -- i j : ℕ
  -- hij : i < j
  -- ⊢ φ i < φ j
  induction j with
  | zero =>
    -- hij : i < 0
    -- ⊢ φ i < φ 0
    exact absurd hij (Nat.not_lt_zero i)
  | succ n ih =>
    -- n : ℕ
    -- ih : i < n → φ i < φ n
    -- hij : i < n + 1
    -- ⊢ φ i < φ (n + 1)
    rcases lt_or_eq_of_le (Nat.lt_succ_iff.mp hij) with h1 | h2
    · -- h1 : i < n
      calc φ i
           < φ n       := ih h1
         _ < φ (n + 1) := hφ n
    · -- h2 : i = n
      calc φ i
           = φ n := by rw [h2]
         _ < φ (n + 1) := hφ n

-- 2ª demostración
-- ===============

example
  (hφ : ∀ n, φ n < φ (n + 1))
  : IsExtraction φ :=
by
  intro i j hij
  -- i j : ℕ
  -- hij : i < j
  -- ⊢ φ i < φ j
  have h : i + 1 ≤ j := hij
  clear hij
  induction j, h using Nat.le_induction with
  | base =>
    -- ⊢ φ i < φ (i + 1)
    exact hφ i
  | succ m _ ih =>
    -- m : ℕ
    -- ih : φ i < φ m
    -- ⊢ φ i < φ (m + 1)
    calc φ i
         < φ m        := ih
       _ < φ (m + 1)  := hφ m

-- 3ª demostración
-- ===============

theorem isExtraction_of_lt_succ
  (hφ : ∀ n, φ n < φ (n + 1))
  : IsExtraction φ :=
strictMono_nat_of_lt_succ hφ
