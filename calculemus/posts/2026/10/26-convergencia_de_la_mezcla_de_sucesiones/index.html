    Reto 25: Si la mezcla de dos sucesiones converge a L, entonces ambas convergen a L

    José A. Alonso

    25-10-2026

    También disponible en:

    English

    Supongamos que la sucesión \(c_n\) es una mezcla de las sucesiones \(a_n\) y \(b_n\); es decir, que \[ (c_0, c_1, c_2, \dots) = (a_0, b_0, a_1, b_1, a_2, b_2, \dots) \]

    Demostrar que si \(c_n\) converge a \(L\), entonces \(a_n\) y \(b_n\) convergen a \(L\).

    Para ello, completar la siguiente teoría

    import Mathlib.Tactic

def SeqLim (a : ℕ → ℝ) (L : ℝ) : Prop :=
  ∀ ε > 0, ∃ k : ℕ, ∀ n ≥ k, |a n - L| < ε

example
  (hc : ∀ n, c n = if Even n
                   then a (n / 2)
                   else b ((n - 1) / 2))
