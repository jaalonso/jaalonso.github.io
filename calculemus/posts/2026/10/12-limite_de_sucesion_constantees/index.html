    Reto 23: La sucesión constante aₙ = L converge a L

    José A. Alonso

    12-10-2026

    El reto de esta semana consiste en demostrar en Lean 4 que la sucesión constante (a_{n} = L) converge a (L). Para ello, completar la siguiente teoría:

    import Mathlib.Tactic

def LimSuc (a : ℕ → ℝ) (L : ℝ) : Prop :=
  ∀ ε > 0, ∃ k, ∀ n ≥ k, |a n - L| < ε

variable {a : ℕ → ℝ}
variable {L : ℝ}

example
  (h : ∀ n, a n = L)
  : LimSuc a L :=
by sorry
