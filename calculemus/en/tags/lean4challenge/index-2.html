    José A. Alonso

    17-05-2026

    Lean 4 Challenges/Analysis/Limits

    Prove that the sequence defined by 1, -1, 1, -1, ... does not converge.

    To do so, the following proof in Lean 4 is to be completed:

    import Mathlib.Data.Real.Basic
import Mathlib.Tactic

variable {a : ℕ → ℝ}

def SeqLim (a : ℕ → ℝ) (L : ℝ) : Prop :=
  ∀ ε > 0, ∃ N : ℕ, ∀ n ≥ N, |a n - L| < ε

def SeqConv (a : ℕ → ℝ) : Prop :=
  ∃ L, SeqLim a L

example
  (ha : ∀ n, a n = (-1) ^ n)
  : ¬ SeqConv a :=

    José A. Alonso

    10-05-2026

    Lean 4 Challenges/Analysis/Limits

    In Lean, a sequence \(a₀, a₁, a₂,...\) can be represented by a function \(a : ℕ → ℝ\) so that \(a(n)\) is \(aₙ\).

    The statement that \(L\) is the limit of the sequence \(a\) is defined by

    def SeqLim (a : ℕ → ℝ) (L : ℝ) : Prop :=
  ∀ ε > 0, ∃ k : ℕ, ∀ n ≥ k, |a n - L| < ε

    Proof challenges in Lean 4

    José A. Alonso

    09-05-2026

    Lean 4 Challenges

    I have started publishing the series Mathematical challenges in Lean 4.

    The format is simple: each week I will post a mathematical problem so that anyone interested can share their solutions in Lean 4.

    At the end of the week I will publish the solutions to the challenge, which will follow this scheme:

    1. A solution in natural language.
    2. Several Lean 4 formalizations, from least to most detailed:
      1. The most automated one, usually with grind.
      2. Others using more specific tactics, such as norm_num, ring, positivity or linarith.
      3. A final proof in which those tactics are replaced by specific lemmas.

    Through this process of successive refinement, the aim is for the final proof to correspond, as far as possible, to the one written in natural language.
