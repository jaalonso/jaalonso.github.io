    Challenge 23: The constant sequence aₙ = L converges to L

    José A. Alonso

    12-10-2026

    Also available in:

    Español

    Prove that the constant sequence \(a_{n} = L\) converges to \(L\).

    To do this, complete the following theory:

    import Mathlib.Tactic

def SeqLim (a : ℕ → ℝ) (L : ℝ) : Prop :=
  ∀ ε > 0, ∃ k, ∀ n ≥ k, |a n - L| < ε

variable {a : ℕ → ℝ}
variable {L : ℝ}

example
  (h : ∀ n, a n = L)
  : SeqLim a L :=
by sorry
