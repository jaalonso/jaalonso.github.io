    Si (∃z ∈ ℝ)[x < z < y], entonces x < y.

    José A. Alonso

    15-12-2023

    Análisis/Números reales

    Demostrar con Lean4 que si \((∃z ∈ ℝ)[x < z < y]\), entonces \(x < y\).

    Para ello, completar la siguiente teoría de Lean4:

    import Mathlib.Data.Real.Basic
variable (x y : ℝ)

example : (∃ z : ℝ, x < z ∧ z < y) → x < y :=
by sorry
